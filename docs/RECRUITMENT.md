# CamGeo Recruitment & Outreach Plan

Goal: **10–15 active contributors by the end of Phase 1 (week 8)**, including at least 5 people based in Cameroon and at least 3 developers.

This plan is run by the Community & Outreach WG. It deliberately excludes LinkedIn; we recruit where our people actually are: mapping communities, universities, developer groups and open data forums.

## 1. Who we need

| Profile | What they do | How many (target) |
|---|---|---|
| Developers (Python / GEE JavaScript) | Build the pipeline (Stages 2, 3, 5, 6) | 3–4 |
| GIS / remote sensing specialists | Review methods, check mosaics, quality control | 2–3 |
| Local validators (no coding needed) | Label and check samples with local knowledge | 4–6 |
| Documentation & outreach writers | Keep docs clear, translate EN/FR, run calls | 1–2 |

## 2. Where to find them

| Segment | Channels | First contact |
|---|---|---|
| Local mappers | OpenStreetMap Cameroon: `talk-cm` mailing list, Facebook group, WikiProject Cameroon | Post a short intro + one concrete task (sample labelling) |
| Universities | Geography / forestry / agronomy departments: Yaoundé I, Douala, Dschang, Buea, Ngaoundéré; YouthMappers chapters | Email a lecturer or student club with the FR message below |
| Central Africa remote sensing network | OSFAC community (uses Collect Earth and GEE already), OFAC/COMIFAC platform users | Ask to present CamGeo in a community call |
| African data science | Zindi discussions, Data Science Africa, Deep Learning Indaba groups | Share the open benchmark idea and the future Hugging Face dataset |
| Cameroonian developers (incl. diaspora) | GDG Douala / GDG Yaoundé, dev WhatsApp/Telegram groups, GitHub topic `cameroon` | Share the repo and a `good first issue` |
| Forest / environment experts | Users of the WRI/MINFOF Forest Atlas of Cameroon, local NGOs | Propose reviewing the class legend (Level 3 RFC) |

## 3. Message templates

### English

> Hi [name] — I'm starting CamGeo, an open source project producing annual land cover maps of Cameroon (7 regions, including the Grand Ouest highlands), plus fully documented training data for AI models. Everything is free and open, inspired by MapBiomas (Brazil) and FLAIR-HUB (France). We're looking for [profile] to [one concrete task, e.g. validate 20 satellite-image samples / review a GEE script]. It's community work, not a paid gig — but every release credits contributors publicly and the dataset gets a citable DOI. Governance is collegial: you can vote on decisions from your first contributions. Interested in a 15-minute call, or in trying a `good first issue`?

### Français

### Rules for outreach

- Personalize every message (name, why *them*). No mass copy-paste.
- One concrete, small task per message. Never ask for "help" in the abstract.
- Respect each community's posting rules; ask moderators first when required.
- Answer every reply within 48 hours, even to say "not now".

## 4. Onboarding path (first 14 days)

1. Reply → invite to read README + pick a `good first issue` or a labelling batch.
2. First contribution merged or 20 samples labelled → public thanks in the community thread.
3. Day 14 check-in: what was hard? Fix the docs based on the answer.

## 5. Incentives (no money, real value)

- **Public credit** in every release note and in `CITATION.cff`.
- **Citable work**: each data collection gets a DOI via Zenodo — contributors can list it on their CV.
- **Skills**: hands-on GEE, STAC, open source workflow — useful and demonstrable.
- **Influence**: real voting rights through lazy consensus and RFCs (see GOVERNANCE.md).
- **Growth path**: contributor → maintainer → elected steering committee member.

## 6. 30 / 60 / 90 day cadence

- **Days 0–30**: 30 personalized messages (10 OSM-CM, 10 universities, 10 data science). Target: 5 onboarded.
- **Days 31–60**: first public community call + one online labelling workshop. Target: 3 merged contributions.
- **Days 61–90**: every active contributor invites one person. Target: 10–15 active, 2 maintainer nominations.

## 7. KPIs

- Reply rate to outreach ≥ 20%
- Onboarding → first contribution ≤ 14 days
- 60-day retention of active contributors ≥ 50%
- If after 60 days we have fewer than 5 active contributors: stop, review the plan in a community retrospective, rewrite the offer.
